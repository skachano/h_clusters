# 単位

!!! info "前提知識"
    なし。

量子化学は独自の単位を使い、論文やプログラム、そしてこのウィキも、いくつものエネルギー単位を自由に混ぜて使う。このページは参照用である。各単位が何か、どう換算するか、どのくらいの大きさの数を予想すべきかをまとめる。

## 原子単位

**原子単位** (a.u.) では、電子の質量、電気素量、換算プランク定数 $\hbar$、$4\pi\varepsilon_0$ がすべて 1 になる。するとシュレーディンガー方程式には定数が何も残らない。このウィキの式が素っ気なく見えるのはそのためである。プログラムは内部では原子単位で計算している。

| 量 | 原子単位 | 値 |
|---|---|---|
| 長さ | ボーア ($a_0$) | 0.529177 Å |
| エネルギー | ハートリー ($E_h$) | 27.2114 eV |
| 質量 | 電子の質量 ($m_e$) | 1 amu = 1822.89 $m_e$。陽子は 1836.15 $m_e$ |

水素原子の基底状態エネルギーはちょうど −½ ハートリーであり、電子と原子核の間の距離として最も確率が高いのはちょうど 1 ボーアである。

## エネルギーの単位

| 単位 | 1 ハートリー = | 出てくる場面 |
|---|---|---|
| ハートリー (Eh) | 1 | ORCA 出力の全エネルギー |
| eV | 27.2114 | 結合エネルギー、イオン化エネルギー |
| kcal/mol | 627.509 | 化学での相対エネルギー。このプロジェクトの選抜の幅 |
| kJ/mol | 2625.50 | 同上、SI 寄り |
| cm⁻¹ | 219 474.6 | 振動数 |
| K ($E/k_B$ として) | 315 775 | 温度 |

kcal/mol と kJ/mol は分子 *1 モルあたり*のエネルギーであり、eV とハートリーは分子 1 個あたりである。1 eV = 23.06 kcal/mol = 8065.5 cm⁻¹。

!!! note "波数"
    cm⁻¹ 単位の波数 $\tilde\nu$ は、そのエネルギーをもつ光の 1 cm あたりの波の数であり、$E = hc\tilde\nu$ である。分光学では振動をこの形で報告する。ORCA は振動数を cm⁻¹ で出力するが、厳密にいえばそれは波数である。

## エネルギーの大きさ

このプロジェクトで重要になる数は 6 桁にわたる:

| エネルギー | eV | kcal/mol |
|---|---|---|
| [H₁₀](app:s/10/0/1) の全エネルギー (の大きさ) | ≈ 160 | ≈ 3700 |
| [H₂](app:s/2/0/1) の結合 ($D_e$) | 4.75 | 110 |
| [H₃⁺](app:s/3/1/1) → H₂ + H⁺ | 4.6 | 106 |
| [H⁻](app:s/1/-1/1) → H + e⁻ (電子親和力) | 0.75 | 17 |
| [H₅⁺](app:s/5/1/1) → H₃⁺ + H₂ ($D_e$、このプロジェクトの CCSD(T)) | 0.37 | 8.5 |
| H₂ の零点エネルギー | 0.27 | 6.2 |
| 「化学的精度」 | 0.043 | 1 |
| 298 K での熱エネルギー $k_BT$ | 0.026 | 0.59 |
| C₂ᵥ と D₂d の H₅⁺ の差 (CCSD(T)) | 0.006 | 0.13 |

ここから 2 つのことが言える:

- **全エネルギーは巨大で、化学はごく小さな差の中にある。** 0.1 kcal/mol の相対エネルギーは、ハートリー単位の全エネルギーの小数第 5 位の差である。計算は、気にしている差よりはるかに厳しく収束させなければならない (すべての入力に `TightSCF` がついているのはそのため)。
- **弱い結合は熱エネルギーと競合する。**数 kcal/mol で結合したクラスターは室温で簡単にばらばらになる ([熱化学](../techniques/thermochemistry.md))。

## h_clusters での登場箇所

- `worker/src/hclust/units.py` に換算係数がある (CODATA 2018): `BOHR_TO_ANGSTROM`、`HARTREE_TO_EV`、`HARTREE_TO_KCAL`。
- `result` テーブルのエネルギーはハートリー、構造は Å で保存される。
- キャンペーンのしきい値は kcal/mol 単位である: 昇格の `energy_window_kcal: 15`、重複判定の 0.1 kcal/mol の幅。
