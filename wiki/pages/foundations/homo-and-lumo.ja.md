# HOMO と LUMO

!!! info "前提知識"
    [ハートリー–フォック法](../methods/hartree-fock.md) (軌道と軌道エネルギー)、[スピンと多重度](spin-and-multiplicity.md)

電子は軌道を下から順に埋めていく。**HOMO** は最高被占分子軌道 (highest occupied molecular orbital)、**LUMO** は最低空分子軌道 (lowest unoccupied molecular orbital) である。この 2 つは、分子がもっている電子と、さらに電子を受け入れる余地との境目 (フロンティア) にあたる。そのエネルギーはどの SCF 計算でもただで得られる副産物で、手早い見積もりを与えてくれる: 電子を 1 個取り去るのがどれだけ難しいか (HOMO)、余分な電子がとどまれるか (アニオンの HOMO)、閉殻がどれだけ不活性か (両者のギャップ)。どの見積もりにも決まった外れ方があり、このプロジェクトはそのほとんどに出くわしている。

## 考え方

### エネルギー準位としての軌道

ハートリー–フォック法は軌道 1 つにつき 1 つの軌道エネルギー $\varepsilon_i$ を与え、軌道の数は基底関数の数と同じである。$N$ 個の電子は低いほうから軌道に入り (閉殻なら 1 つの軌道に 2 個)、残りは空のまま**仮想軌道**になる。

$$
\varepsilon_\text{HOMO} = \max_{i\,\in\,\text{occ}} \varepsilon_i, \qquad
\varepsilon_\text{LUMO} = \min_{a\,\in\,\text{virt}} \varepsilon_a, \qquad
\text{gap} = \varepsilon_\text{LUMO} - \varepsilon_\text{HOMO}
$$

[ハートリー–フォック法](../methods/hartree-fock.md#example-h2-from-scratch)の [H₂](app:s/2/0/1) の例には軌道が 2 つしかない: 電子 2 個を収める結合性の $\sigma_g$ (−0.578 ハートリー、HOMO) と、空の反結合性の $\sigma_u$ (+0.670 ハートリー、LUMO) である。

**開殻。**非制限 HF (UHF) では、上向きスピンと下向きスピンの電子が別々の軌道と別々のエネルギーをもつので、HOMO も LUMO も 2 つずつある。二重項では、最も高い被占軌道は 1 電子だけが入った軌道 (SOMO) である。このプロジェクトでは、両方のスピンを通じて最も高い被占軌道と最も低い空軌道をとる。

### HOMO: イオン化エネルギー (クープマンスの定理)

軌道 $i$ から電子を 1 個取り去り、他の軌道はすべて凍結したままにすると、エネルギーはちょうど $-\varepsilon_i$ だけ上がる。したがって

$$
\text{IE} \approx -\varepsilon_\text{HOMO}
$$

これが**クープマンスの定理**である。符号の逆な 2 つの誤差が無視されている:

- **緩和。**1 個が去ると残りの電子が配置を変え、カチオンのエネルギーが下がる。これだけなら $-\varepsilon_\text{HOMO}$ は大きすぎる。
- **相関。**HF は電子の多い化学種ほど多くの相関エネルギーを取りこぼすので、中性分子が高すぎ、IE は小さすぎる。

ふつうの分子では両者が部分的に打ち消し合い、$-\varepsilon_\text{HOMO}$ は測定された**垂直**イオン化エネルギーと 1 eV 程度以内で一致する。垂直というのは、軌道が 1 つの構造に属しているからである: この見積もりは、カチオンが自分自身の構造へ緩和することについて何も知らない。

### LUMO: 電子親和力、ただしはるかに当てにならない

同じ議論で $\text{EA} \approx -\varepsilon_\text{LUMO}$ となるが、この見積もりは悪い。仮想軌道は、自分が含まれていない $N$ 個の電子すべての場の中で計算される: 付け加えた電子はそのすべてから反発を受け、しかもそのまわりで電子が緩和することは許されない。仮想軌道は高すぎ、広がりすぎた形で得られる。

基底関数系がこれをさらに悪くする。中性分子が余分な電子を束縛できないとき、本当の LUMO はエネルギーゼロの自由電子であり、有限の基底ではそれを表せない。計算は代わりに、手持ちの最も広がった関数を、ゼロより上のどこかに報告する。その数値は基底を変えるたびに変わる。広がった基底での中性分子の LUMO は、分子についてよりも基底について多くを語っている ([非束縛アニオン](../pitfalls/unbound-anions.md))。

### ギャップ

クープマンスの描像では、ギャップは $\text{IE} - \text{EA}$、つまり**基本ギャップ**である: 電子を 1 つの分子から遠く離れた別の分子へ移すのに要するエネルギー。これは励起エネルギーではない。光子は電子を 1 つの分子の中で動かし、電子はそこで自分が残した正孔に引きつけられたままなので、励起エネルギーはもっと低い。

定性的な尺度としては、ギャップは役に立つ:

- **大きなギャップ**は、電子を手放すことも受け取ることも容易でない閉殻を意味する: 化学的に硬く、不活性である。ギャップの半分 $(\text{IE} - \text{EA})/2$ がピアソンの**化学的硬さ**である。
- **小さなギャップ**は、近くの電子配置が競合していることを意味する。そのとき単一の行列式では分子をうまく記述できず、分母が軌道エネルギー差である摂動論は破綻する ([MP2](../methods/mp2.md))。
- **フロンティア軌道**の考え方 (福井) は、反応を一方の分子の HOMO と他方の LUMO の重なりで説明する。

### DFT の軌道

コーン–シャム DFT にも軌道と軌道エネルギーがある。厳密な汎関数なら HOMO のエネルギーは垂直 IE の符号を変えたものに厳密に等しいが、近似汎関数ではそうならない。[自己相互作用誤差](../pitfalls/self-interaction-error.md)は各電子に自分自身との反発を許し、HOMO を、しばしば数 eV も押し上げる。アニオンで最も悪い: r²SCAN-3c は束縛された [H⁻](app:s/1/-1/1) の HOMO を +6.4 eV、ゼロのはるか上に置く。このためこのプロジェクトはフロンティア軌道を HF から読み取る。

## キャンペーンからの例 { #examples-from-the-campaign }

CCSD(T)/aug-cc-pVTZ 参照計算 (L2) の HF 軌道。基底状態について eV 単位で示し、電子を 1 個取り去る CCSD(T) エネルギー (断熱、判定から) と並べる:

| 化学種 | 組成 | HOMO | LUMO | ギャップ | −HOMO | CCSD(T) の IE または脱離エネルギー |
|---|---|---|---|---|---|---|
| H | H | −13.60 | +0.42 | 14.03 | 13.60 | 13.60 |
| H₂ | H₂ | −16.16 | +1.43 | 17.59 | 16.16 | 15.52 |
| [H₃](app:s/3/0/2) | H₂·H | −13.64 | +0.45 | 14.09 | 13.64 | 9.00 |
| [H₄](app:s/4/0/1) | H₂·H₂ | −16.01 | +1.31 | 17.32 | 16.01 | 13.47 |
| H⁻ | H⁻ | −1.24 | +6.59 | 7.83 | 1.24 | 0.73 |
| [H₃⁻](app:s/3/-1/1) | H₂·H⁻ | −1.28 | +3.85 | 5.13 | 1.28 | 0.78 |
| [H₉⁻](app:s/9/-1/1) | (H₂)₄·H⁻ | −1.57 | +3.68 | 5.25 | 1.57 | 0.99 |
| [H₃⁺](app:s/3/1/1) | H₃⁺ | −32.91 | −5.38 | 27.53 | | |
| [H₅⁺](app:s/5/1/1) | H₃⁺·H₂ | −24.39 | −4.42 | 19.97 | | |
| [H₉⁺](app:s/9/1/1) | H₃⁺·(H₂)₃ | −21.92 | −3.53 | 18.39 | | |

表の読み方:

- **H 原子: クープマンスは厳密。**電子が 1 個なら緩和するものも相関するものもないので、$-\varepsilon_\text{HOMO}$ = 13.60 eV がそのままイオン化エネルギーである。
- **H₂: 典型的なクープマンスの誤差。**16.16 eV に対して 15.52 eV。差の一部は垂直と断熱の違いである: [H₂⁺](app:s/2/1/2) の結合はより長い。
- **H₃ と H₄: 垂直は断熱ではない。**クラスターの HOMO は、最もゆるく結びついたユニットの HOMO である: H₂·H では H 原子の 1s (−13.64 eV)、H₂·H₂ では H₂ の $\sigma_g$ (−16.01 eV)。キャンペーンのすべての中性二重項は HOMO が −13.6 eV に、すべての中性一重項は −16.0 eV 付近にある。しかしイオン化されると、これらのクラスターは H₃⁺ の核のまわりに組み変わり (H₃⁺、[H₄⁺](app:s/4/1/2) では H₃⁺·H)、大きなエネルギーを放出する。そのため断熱 IE はクープマンスより 4.6 eV (H₃)、2.5 eV (H₄) 低い。軌道エネルギーにはそれを知るすべがない。
- **H⁻ の仲間: HOMO が余分な電子の目印になる。**束縛されたアニオン一重項はどれも HOMO が −1.2 から −1.6 eV の間にあり、H⁻ イオンの孤立電子対である。H₂ が 1 つ加わるたびに HOMO は下がり (H⁻ から H₉⁻ まで −1.24、−1.28、−1.35、−1.45、−1.57 eV)、それとともに脱離エネルギーも上がる (0.73 から 0.99 eV): H₂ 分子が電荷を安定化している。クープマンスはどちらも約 0.5 eV 過大に見積もる。
- **HF の H⁻: HOMO は負なのに束縛はない。**HF は H⁻ をまったく束縛しない: H⁻ の HF エネルギーは H のそれより上にある。それでも HOMO が −1.24 eV なのは、クープマンスが軌道を凍結したままにするからで、広がったアニオンの軌道に取り残された残りの電子は、出来の悪い H 原子にすぎない。H⁻ は相関によってのみ束縛され、それを与えるのが CCSD(T) である。
- **中性分子の LUMO: 基底関数系の人工物。**どの中性分子も +0.4 から +1.4 eV で、すべて aug-cc-pVTZ の分散関数である。H 原子には束縛されたアニオンがある (EA 0.75 eV) のに、LUMO は正である (+0.42 eV): LUMO による EA の見積もりは符号さえ外す。STO-3G では H₂ の LUMO は +18.2 eV の反結合性 $\sigma_u$ で、まったく別の軌道である。
- **カチオン: 負の LUMO。**カチオンは電子を引きつけるので、空軌道でさえ束縛されている。
- **H₃⁺ はキャンペーンで最大のギャップをもつ** (27.5 eV): 3 個の陽子に広がった結合性軌道に電子が 2 個入った、最も単純な芳香族系である。H₂ 分子を加えると、正電荷を分け合う配位子が増えるにつれて、HOMO は −32.9 eV から自由な H₂ の −16.2 eV へ向かって上がっていく。

### 非束縛アニオンのフラグ { #the-unbound-anion-flag }

余分な電子が束縛されていないアニオンでも、最も広がった関数の擬連続状態から HOMO が返ってくる。aug-cc-pVTZ と def2-TZVPPD ではその状態は +1 eV 付近にあり、束縛されたアニオンは +0.2 eV (ωB97X-D4) または −0.7 eV (HF) より下にある。キャンペーンはその間の隔たりを安価な判定に使う: HOMO が +0.5 eV より上のアニオンには `unbound` のフラグが立ち、その構造は信用されない。決定的な判定はやはりエネルギーである: アニオンが中性分子と自由電子の和より下にあるかどうか ([イオン化エネルギーと電子親和力](../techniques/ionization-and-electron-affinity.md))。

## h_clusters での登場箇所

- **解析。**`worker/src/hclust/parse.py` の `_frontier_orbitals` は ORCA の出力の最後の `ORBITAL ENERGIES` ブロックを読み、両方のスピンを通じて最も高い被占軌道と最も低い空軌道をとる。MP2 と CCSD(T) のジョブでは、これらは HF 参照の軌道である。ハートリー単位で保存される (`result` テーブルの `homo`、`lumo`)。
- **非束縛アニオン。**`worker/src/hclust/levels.py` の `Level.unbound_homo_ev` が、ωB97X-D4、ωB97M-V、RI-MP2、CCSD(T) の HF 参照について +0.5 eV のしきい値を定める。r²SCAN-3c にはない: 自己相互作用誤差と分散関数の欠如のため、束縛された H⁻ でさえ +4 eV より上に来る (`doc/Plan.md`、フェーズ 4)。
- **判定。**状態の参照構造は、自身の HOMO によっても、その構造を求めたジョブの HOMO によっても、非束縛アニオンであってはならない (`worker/src/hclust/analysis/verdicts.py`)。
- ウェブアプリ: 各化学種ページの性質の中の「HOMO / LUMO (HF)」(例: [H₃⁺](app:s/3/1/1))、そしてトレンドページでグリッド全体にわたる [HOMO–LUMO ギャップ](app:trends)。
