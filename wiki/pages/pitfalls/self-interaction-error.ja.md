# 自己相互作用誤差

!!! info "前提知識"
    [DFT](../methods/dft.md)、[ハートリー–フォック法](../methods/hartree-fock.md)

近似的な DFT では、電子が自分自身の電荷から小さな反発を受ける。この**自己相互作用誤差**は電子を本来より広げようとする。電子の少ない結合は長すぎ、弱すぎたり強すぎたりし、ゆるく保持された電子は非束縛になり、電荷が非局在化した構造は低すぎるエネルギーになる。電子が少なく、電荷をもつ化学種の多い水素クラスターは、その格好の見本である。

## 考え方

### どこから来るのか

DFT のクーロンエネルギー $J[\rho]$ は電子密度全体の自分自身との反発であり、各電子とそれ自身との反発も含んでいる。電子 1 個ならこれはまったくのナンセンスで、反発する相手がいない。厳密な汎関数では交換相関エネルギーがこれをちょうど打ち消す:

$$
J[\rho_1] + E_\text{xc}[\rho_1] = 0 \quad \text{(任意の一電子密度 } \rho_1 \text{ について)}
$$

[ハートリー–フォック法](../methods/hartree-fock.md#step-2-the-mean-field)はこれを自動的に満たす (交換が自己クーロン項を打ち消す)。近似汎関数は満たさず、自己反発がいくらか残る。

### 何をもたらすか

自分自身と反発する電子は、広がることでエネルギーを下げる。そのため近似的な DFT は**非局在化した**電子や電荷を好む。これはしばしば**非局在化誤差**と呼ばれる:

- **伸びた一電子結合**が安定すぎる: 電子が 2 つの陽子にわたって広がった [H₂⁺](app:s/2/1/2) は、遠い距離でエネルギーが低すぎる。
- **アニオン**の束縛が弱すぎる: 余分な電子の自己反発がそれを押し出し、ときには分子から完全に追い出す。
- **共有された電荷**が好まれる: 2 つの [H₂](app:s/2/0/1) ユニットの間に対称に置かれた陽子のほうが、局在した [H₃⁺·H₂](app:s/5/1/1) よりよく見える。
- 反応の**障壁**が低すぎる: 遷移状態は普通より非局在化しているからである。

混成汎関数は HF 交換を混ぜることでこれを減らし、長距離補正混成汎関数 (ωB97X) は長距離で 100 % の HF 交換を使う。どちらも誤差を取り除きはしない。

## このプロジェクトの例 { #examples-from-this-project }

**[H₂⁺](app:s/2/1/2)、電子 1 個。**ここではハートリー–フォック法が厳密なので、DFT のずれはすべて自己相互作用によるものである:

| [H₂⁺](app:s/2/1/2) | r²SCAN-3c (L0) | ωB97X-D4 (L1) | HF (基底内で厳密) | 厳密値 |
|---|---|---|---|---|
| 結合長 | 1.083 Å | 1.105 Å | 1.058 Å | 1.057 Å |
| 調和振動数 | — | 2074 cm⁻¹ | 2322 cm⁻¹ | 2322 cm⁻¹ |
| $D_e$ (→ [H + H⁺](app:s/2/1/2)) | 2.91 eV | 2.91 eV | 2.79 eV | 2.79 eV |

結合は長すぎ、やわらかすぎるのに、強すぎる。電子は本来以上に 2 つの陽子に広がることを好んでいる。

**[H⁻](app:s/1/-1/1)、アニオン。** H の電子親和力は 0.754 eV である。ωB97X-D4 は 0.20 eV を与え、r²SCAN-3c では [H⁻](app:s/1/-1/1) は非束縛になる (−1.57 eV。[分散関数](diffuse-functions.md)がないことでさらに悪化している)。HF 軌道に基づく MP2 と CCSD(T) は 0.48 eV と 0.73 eV を与える ([電子親和力](../techniques/ionization-and-electron-affinity.md))。

**[H₅⁺](app:s/5/1/1)、共有された陽子。**このプロジェクトのどの DFT レベルも、さらに ωB97M-V も、C₂ᵥ の [H₃⁺·H₂](app:s/5/1/1) 構造を、陽子が 2 つの [H₂](app:s/2/0/1) ユニットに等しく共有された D₂d 構造 (1.13 Å の結合 4 本) に変えてしまう。MP2 は C₂ᵥ を保つ。MP2 では D₂d 構造は鞍点 (546i cm⁻¹) であり、CCSD(T) は C₂ᵥ を 0.13 kcal/mol 低く置く (`doc/Plan.md`、フェーズ 3)。

## 身を守る方法

- 自己相互作用のない手法、MP2 や CCSD(T) と DFT を照合する。計画ではすべての状態についてこれを行う。
- アニオン、奇数電子の陽イオン、電荷が共有され得る構造には特に疑ってかかる。
- 一電子系には HF を使う。HF は厳密である。

## [h_clusters](https://github.com/skachano/h_clusters) での登場箇所 { #where-this-appears-in-h_clusters }

- **L1M** (RI-MP2) 構造レベルがあるのは [H₅⁺](app:s/5/1/1) の結果のためである (`worker/src/hclust/levels.py` のコメント)。
- アンカーテスト (`worker/tests/test_anchors.py`) は、DFT の [H₂⁺](app:s/2/1/2) 結合長を「必ず失敗すべきテスト」(strict xfail) として保持している。それを「直してしまう」変更があれば気づける。
- DFT と MP2 の両方の構造での CCSD(T) 一点計算が、各構造を決める (`campaigns/baseline.yaml` の `dft_ref`、`mp2_ref`)。
- [ウェブアプリ](app:): [「手法比較」](app:benchmark)ページで各構造レベルの $D_e$ を CCSD(T) と比べている。DFT が失敗するのはアニオンである。
