# 半経験的タイトバインディング (GFN2-xTB)

!!! info "前提知識"
    [ハートリー–フォック法](hartree-fock.md)、[DFT](dft.md)

GFN2-xTB は**半経験的**手法である。DFT と同じ種類の軌道計算を行うが、積分のほとんどを、参照データに合わせたパラメータをもつ簡単な式で置き換えている。DFT より何千倍も速く、何千もの構造にわたる大域探索を回せるほどである。その代償として、精度はパラメータ化の出来しだいであり、水素クラスターはそれが合わせられた化学の範囲の外にある。

## 考え方

xTB (「拡張タイトバインディング」、Grimme らによる) は、DFT が時間をかけているところをすべて削っている:

- **最小基底、価電子のみ**: 原子 1 個あたり数個の関数。
- **近似積分**: ハミルトニアン行列要素を、実際のハミルトニアンの積分ではなく、重なりと当てはめた元素パラメータから計算する。
- **簡略化した静電相互作用**: 電子間反発を原子の部分電荷と多重極で扱う。
- **分散補正を内蔵** (D4)。非共有結合性相互作用のため。

SCF ループは今も回るが、小さな行列と安価な要素の上で回る。「GFN」は目標を表す: **G**eometries (構造)、振動 **F**requencies (振動数)、**N**oncovalent interactions (非共有結合性相互作用)。パラメータが主に合わせられたのはこれらの性質である。

## このプロジェクトで起きたこと

フェーズ 0 の動作確認は、最も単純な本物のクラスターである H₃⁺ だった (`doc/Plan.md`、フェーズ 0 の知見):

| 手法 | 最も低い構造 | 直線と三角形の差 |
|---|---|---|
| GFN2-xTB | **直線**、r = 1.03 Å | 直線が 0.9 kcal/mol *低い* |
| r²SCAN-3c | 三角形、r = 0.870 Å | 直線が 39.4 kcal/mol 高い |
| CCSD(T)/cc-pVTZ | 三角形、r = 0.875 Å | 直線が 40.5 kcal/mol 高い |

GFN2-xTB は H₃⁺ の形を定性的に間違える。水素のパラメータは普通の分子の中の水素 (C–H 結合や O–H 結合) に合わせられたもので、三中心二電子結合や裸の陽イオン性水素クラスターに合わせたものではない。これはパラメータ化された手法についての一般的な教訓である。内挿はうまくいくが外挿は下手であり、失敗しても何の警告も出ない。

その結果:

- xTB は**構造の提案だけ**に使い、順位づけには決して使わない。GOAT のエネルギー幅は広くとってあるので (`engines/orca.py` の `MaxEn 30` kcal/mol)、xTB が高すぎると評価した構造も次へ渡される。
- 選別を行うのは xTB ではなく r²SCAN-3c (L0) である。
- xTB を使った GOAT は、テンプレートとランダム探索が見つけなかったものを何も見つけなかったので、ベースラインキャンペーンでは既定で無効になっている (フェーズ 3 の知見)。

## h_clusters での登場箇所

- `worker/src/hclust/levels.py` の `Level("XTB", "XTB", kind="xtb")`。
- ORCA の `! GOAT-EXPLORE XTB` を通じて使う ([構造探索](../techniques/structure-search.md))。ORCA は worker の `Dockerfile` で設定された環境変数 `XTBEXE` を通じて `xtb` の実行ファイルを見つける。
