# 基底関数系

!!! info "前提知識"
    [ハートリー–フォック法](hartree-fock.md)

コンピュータは軌道を任意の 3 次元関数として保存できない。ここに出てくるどの手法も、軌道を決まった関数の有限な集まり、すなわち**基底関数系**で展開し、展開係数だけを最適化する。基底関数系はあらゆる「計算レベル」(CCSD(T)/aug-cc-pVTZ のような「手法/基底」の組) の半分を占め、相関手法ではしばしば誤差の大きいほうの原因になる。

## 考え方

### なぜガウス関数か

水素原子の厳密な軌道は $e^{-\zeta r}$ (スレーター関数) のように減衰する。原子核のところで鋭いカスプがあり、遠くでは指数関数的にゆっくり減衰する。しかし複数の原子にまたがるスレーター関数の積分を計算するのは非常に難しい。ガウス関数 $e^{-\alpha r^2}$ は形が間違っている (カスプがなく、裾の減衰が速すぎる) が、異なる原子上の 2 つのガウス関数の積はその間にある別のガウス関数になるので、すべての積分が閉じた式で書ける。[ハートリー–フォック法](hartree-fock.md#example-h2-from-scratch) のおもちゃのコードが数行で全部の積分を計算できるのはそのためである。

形の誤りを補うには、1 つの軌道に複数のガウス関数を使う。**縮約**関数は、スレーター関数に似せるように当てはめたガウス関数 (「原始関数」) の決まった組み合わせである。STO-3G は 3 つ使う。

### よりよい基底をつくる

| 要素 | 加えるもの | 理由 |
|---|---|---|
| **分割原子価** (二重ζ、三重ζ、…) | 価電子軌道 1 つにつき大きさの違う関数を 2、3、… 個 | 分子の中で軌道が広がったり縮んだりできる |
| **分極**関数 | より高い角運動量: H に p 関数や d 関数 | 結合のように、軌道が曲がったり原子核から外れたりできる |
| **分散**関数 | 非常に広がった関数 (小さな α) | 弱く束縛された電子: アニオン、弱い相互作用 ([分散関数](../pitfalls/diffuse-functions.md)) |

### 名前

このプロジェクトには 2 つの系列が出てくる:

- **Dunning の相関無撞着**基底、cc-pV**X**Z (X = D、T、Q、5: 二重、三重、… ζ)。X が大きくなるにつれて相関エネルギーが系統的に収束するように設計されている。接頭辞 **aug-** は角運動量ごとに分散関数を 1 つずつ加える。
- **カールスルーエ**基底、def2-SVP、def2-TZVP、def2-TZVPP、…。def2-TZVPP**D** の末尾の **D** は分散関数を加える。

水素原子 1 個あたりの関数の数:

| 基底 | 殻 | 関数の数 |
|---|---|---|
| STO-3G | 1s | 1 |
| cc-pVDZ | 2s1p | 5 |
| cc-pVTZ | 3s2p1d | 14 |
| aug-cc-pVTZ | 4s3p2d | 23 |

したがって aug-cc-pVTZ での [H₁₀](app:s/10/0/1) の計算には 230 個の基底関数がある。[ハートリー–フォック法のページ](hartree-fock.md#the-same-thing-in-orca)で引用した実際の三重項 [H₃⁺](app:s/3/1/3) のジョブには 3 × 23 = 69 個ある。

## 例: 水素原子 { #example-the-hydrogen-atom }

[`h_atom_basis.py`](#the-code) は、$n$ 個の s 型ガウス関数で水素原子を解く。指数は等比数列 $\alpha_k = a\,b^k$ (even-tempered 型) をなし、$a$ と $b$ は各 $n$ について最適化する。この方法は[変分的](../foundations/schrodinger-equation.md#the-variational-principle)なので、関数を足すたびにエネルギーは厳密値 −0.5 ハートリーへ向かって下がる:

```text
 n   E (hartree)   error (eV)   exponents
 1   -0.424412      2.0569       0.282
 2   -0.485808      0.3862       0.2, 1.32
 3   -0.495825      0.1136       0.158, 0.777, 3.81
 4   -0.498750      0.0340       0.133, 0.547, 2.24, 9.19
 5   -0.499562      0.0119       0.119, 0.428, 1.54, 5.55, 20
 6   -0.499839      0.0044       0.106, 0.35, 1.15, 3.81, 12.6, 41.5
```

最適化は指数を両方向に押し広げる。大きな指数 (狭い関数) は原子核でのカスプをつくるため、小さな指数は裾のためである。関数を 1 つ足すごとに精度はおよそ 3 倍よくなる。このプロジェクトの aug-cc-pVTZ は水素原子を 0.005 eV 高く与え、最適化した s 関数 6 個とほぼ同じ精度である。

## 収束と CBS 極限 { #convergence-and-the-cbs-limit }

HF のエネルギーは基底の大きさに対して速く収束する。相関エネルギーはそうではない。電子が近距離で互いを避ける様子を記述するにはより高い角運動量の関数が次々に必要で、cc-pV$X$Z ではおよそ $X^{-3}$ で収束する。よく使われる対処法は、2 つの基底 (たとえば TZ と QZ) で計算し、完全基底 (CBS) 極限へ**外挿**することである。

基底関数のもうひとつの人為的な効果が**基底関数重なり誤差** (BSSE) である。複合体 A·B では、断片 A が B の基底関数を借りて自分のエネルギーを下げるので、結合が実際より強く見える。カウンターポイズ補正は、各断片を複合体の基底全体で計算することでこれを取り除く。

## h_clusters での登場箇所

- L1 は def2-TZVPPD、L1M と L2 は aug-cc-pVTZ を使う ([RI](resolution-of-identity.md) 用の対応する補助基底も)。r²SCAN-3c (L0) は分散関数をもたない独自の小さな三重ζ基底と一体になっている。
- 分散関数はアニオンだけでなく*すべての*化学種に使い、どの電荷状態も同じように扱われるようにしている (`doc/Plan.md` §2)。
- 基底の大きさで答えが変わる: aug-cc-pVDZ の MP2 は [H₅⁺](app:s/5/1/1) を D₂d に崩すが、aug-cc-pVTZ では C₂ᵥ が保たれる。
- TZ → QZ → CBS の収束の調査は任意レベル L4 である (計画、フェーズ 8)。
- ウェブアプリ: カウンターポイズ補正と基底関数の極限は[「追加計算」](app:studies)ページにある。
