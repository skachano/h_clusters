# 解離チャネル

!!! info "前提知識"
    [ポテンシャルエネルギー曲面](../foundations/potential-energy-surface.md#binding-energy-d_e-and-d_0)

ポテンシャルエネルギー曲面の極小であれば、クラスターは*局所的には*安定である。小さなひずみでは壊れない。ばらばらになることに対して安定かどうかは別の問題である。クラスターが断片に分かれる方法はたくさんあり、そのそれぞれが**解離チャネル**であって、クラスターの安定性はその最も弱いチャネルで決まる。これに答えるには考え得るすべての断片のエネルギーが必要であり、キャンペーンが化学種のグリッド全体を計算するのはそのためである。

## 考え方

### チャネルを数え上げる

H_m^n は 2 つの部分 H_a^p と H_(m−a)^(n−p) に分かれることができ、部分の電荷の和は全電荷に等しい。各部分はこのプロジェクトが計算する化学種 (電荷 −1、0、+1) でなければならない。[H₅⁺](app:s/5/1/1) では 4 つのチャネルがある:

| チャネル | 部分 |
|---|---|
| [H₃⁺ + H₂](app:s/5/1/1) | 予想されるもの: 溶媒和している [H₂](app:s/2/0/1) を失う |
| [H₄⁺ + H](app:s/5/1/1) | 原子を失う |
| [H₄ + H⁺](app:s/5/1/1) | 裸の陽子を失う |
| [H₃ + H₂⁺](app:s/5/1/1) | 電荷が [H₂](app:s/2/0/1) のほうへ行く |

各断片は計算したどのスピン状態でもよく、計画では最もエネルギーの低いものを使う (`doc/Plan.md` §2.2)。厳密には、クラスターがばらばらになるときに全スピンは保存されるので、一部の組み合わせはスピン禁制である。最も低いものをとれば、クラスターの安定性について最も慎重な見積もりになる。

### チャネルの解離エネルギー

$$
\Delta E_\text{channel} = E(\text{H}_a^p) + E(\text{H}_{m-a}^{n-p}) - E(\text{H}_m^n)
$$

各エネルギーは、同じ計算レベルでその化学種について見つかった最も低い値である。正であれば、クラスターは断片よりエネルギーが低い。**最も弱いチャネル**がクラスターの安定性を決める:

$$
D_\text{min} = \min_\text{channels} \Delta E_\text{channel}
$$

同じことを ZPE 込みで ($D_{0,\min}$)、あるいは $\Delta H(T)$ や $\Delta G(T, p)$ として行うこともできる ([熱化学](thermochemistry.md))。最も弱いチャネルはそれらの間で異なることがある。

### 判定 { #verdicts }

計画はこれを他の安定性の確認と組み合わせ、状態ごとに順序のついた判定をひとつ与える (`doc/Plan.md` §2.2):

```mermaid
flowchart LR
  A[unbound_electron] --> B[not_a_minimum] --> C[dissociates] --> D[metastable] --> E[bound] --> F[bound_with_zpe]
```

- `unbound_electron`: 余分な電子を失うアニオン ([電子親和力](ionization-and-electron-affinity.md))。
- `not_a_minimum`: 虚振動数のない構造がない。
- `dissociates`: どの最適化もばらばらになった。
- `metastable`: 極小ではあるが $D_\text{min} < 0$。どれかのチャネルが下り坂であり、障壁の向こうにあるかもしれない。
- `bound`: $D_\text{min} > 0$。
- `bound_with_zpe`: さらに $D_{0,\min} > 0$。

### 生成物か過程か: 再配置と障壁

チャネルの $D_e$ は 2 つの端点を比べる。極小にあるクラスターと、それぞれ自分の極小まで緩和した生成物である。

**再配置はすでに含まれており、それはコストを下げる。** エネルギーは経路によらないので、離れていく途中で原子がどう再配置しても、効くのは端点だけである。生成物自身の構造へ緩和すると、部品を凍結したまま引き離す場合と比べて必ずエネルギーが放出される:

$$
D_\text{frozen} = D_e + E_\text{relaxation} \;\ge\; D_e
$$

$D_e$ (そして緩和した極小での零点エネルギーを含む $D_0$) は*断熱的な*コストであり、その緩和の分はすでに差し引かれている。[H₆⁺](app:s/6/1/2) → [H₅⁺ + H](app:s/6/1/2) では、クラスターにない [H₃⁺](app:s/3/1/1) の三角形ができなければならないので、凍結したままのコストは $D_e$ の 0.30 eV よりずっと大きいだろう。

**$D_e$ が取りこぼすもの: 出口の途中の障壁。** 最小エネルギー経路が生成物のエネルギーより高く上がる (*逆障壁*がある) と、実際のしきい値は経路の頂上になる:

$$
E_\text{threshold} = \max\big(D_e,\ E_\text{TS} - E_\text{cluster}\big)
$$

「どの分解が最も安く*実現*できるか」は、$D_e$ が最も低いチャネルではなく、しきい値が最も低いチャネルである。衝突誘起解離の実験が測るのはまさにこのしきい値である。

- **障壁なし:** イオン–分子とファンデルワールスの分解。たとえば H₃⁺(H₂)ₙ → H₃⁺(H₂)ₙ₋₁ + [H₂](app:s/2/0/1)。生成物は最後まで引き合い、何も再配置する必要がないので、しきい値は $D_0$ に等しい。
- **障壁がありうる:** 再配置を必要とする分解。[H₆⁺](app:s/6/1/2) → [H₅⁺ + H](app:s/6/1/2) では障壁はないと予想される。その逆反応は、星間雲で [H₃⁺](app:s/3/1/1) をつくる障壁のないイオン–分子反応 [H₂⁺ + H₂](app:s/4/1/2) → [H₃⁺ + H](app:s/4/1/2) に似ているからである。NEB 計算は CCSD(T) エネルギーで生成物より 16 meV 高い鞍点を見つけるが、調和近似の零点エネルギーを入れるとそれは生成物より 46 meV 低くなるので、しきい値はやはり $D_0$ である ([遷移状態と障壁](transition-states.md#例-どのチャネルに何が必要か))。

**しきい値がすべてでもない。** しきい値のすぐ上では最も安いチャネルが支配的だが、エネルギーが高くなると、遷移領域が「ゆるい」(やわらかい状態が多い) チャネルがそれを上回ることがある。RRKM 理論や位相空間理論がこうした分岐比を予測する。

障壁を見つけるには最小エネルギー経路を計算する。離れていく断片の距離に沿った緩和スキャンや、クラスターと分離した生成物の間の NEB (nudged elastic band) 探索を行い、途中で精密な一点計算をする ([遷移状態と障壁](transition-states.md))。

## 例: H₅⁺

ベースラインキャンペーンの CCSD(T)/aug-cc-pVTZ エネルギー (各化学種の最も低い構造):

| チャネル | 断片のエネルギー (ハートリー) | ΔE (eV) |
|---|---|---|
| [H₃⁺ + H₂](app:s/5/1/1) | −1.341728 − 1.172635 | **0.370** |
| [H₄⁺ + H](app:s/5/1/1) | −1.850284 − 0.499821 | 4.84 |
| [H₃ + H₂⁺](app:s/5/1/1) | −1.672511 − 0.602302 | 6.89 |
| [H₄ + H⁺](app:s/5/1/1) | [H₄](app:s/4/0/1) はこのレベルでまだ計算されていない | — |

E([H₅⁺](app:s/5/1/1)) = −2.527957 ハートリーである。[H₂](app:s/2/0/1) を失うのが群を抜いて安上がりな壊れ方であり、[H₂](app:s/2/0/1) に溶媒和された [H₃⁺](app:s/3/1/1) コアから予想されるとおりである。$D_\text{min}$ = 0.37 eV (8.5 kcal/mol)。ZPE を含めると 5.75 kcal/mol に下がる ([零点エネルギー](zero-point-energy.md#example-h5-h3-h2))。

欠けている行は「閉包性」を示している。[H₅⁺](app:s/5/1/1) を判定するには [H₄](app:s/4/0/1) も終わっている必要がある。

## [h_clusters](https://github.com/skachano/h_clusters) での登場箇所 { #where-this-appears-in-h_clusters }

- チャネルの数え上げと判定はフェーズ 5 (`analysis/fragments.py`) で行う。`Verdict` テーブルには、状態とレベルごとに `d_min`、`d0_min`、判定、最も弱いチャネルが保存される (`doc/Plan.md` §3.4)。
- 陽イオンのチャネルが、§1.2 で予想される偶奇交替の源である。[H₅⁺](app:s/5/1/1)、[H₇⁺](app:s/7/1/1)、[H₉⁺](app:s/9/1/1) ([H₃⁺](app:s/3/1/1) コア + [H₂](app:s/2/0/1) ユニット) は偶数の隣よりも安定なはずである。
- 分解の木とそれに基づくユニット (`analysis/units.py`) は $D_e$ を使うので、すべてのチャネルに障壁がないと仮定している。障壁の研究がこれを確かめたのは [H₅⁺](app:s/5/1/1) と [H₆⁺](app:s/6/1/2) だけである。
- 最適化された 1 つの構造がばらばらになっていないかという*構造的な*確認は別物である。[構造探索](structure-search.md#how-this-project-does-it)の 3.5 Å の接触カットオフがそれにあたる。
- [ウェブアプリ](app:): 各化学種ページにチャネルの一覧と分解の木がある。例: [H₅⁺](app:s/5/1/1)。
