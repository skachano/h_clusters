# 点群と対称性

!!! info "前提知識"
    なし。ただし例を読むには[振動数](frequencies.md)が役立つ。

分子の**点群**とは、分子を変わらないように見せる対称操作 (回転、鏡映、反転) の集まりである。点群は形の簡潔な名前である。「D₃h」と言えば [H₃⁺](app:s/3/1/1) が正三角形であることが分かる。対称性には結果も伴う。いくつかの振動を縮退させ、回転エントロピーを決め、最適化を対称な経路の上にとどめる。

## 考え方

### 対称操作

| 記号 | 操作 |
|---|---|
| $E$ | 恒等操作 (何もしない) |
| $C_n$ | 軸のまわりに $360°/n$ 回転する |
| $\sigma$ | 平面で鏡映する (主軸に垂直な $\sigma_h$、主軸を含む $\sigma_v$) |
| $i$ | 中心について反転する: $(x, y, z) \to (-x, -y, -z)$ |
| $S_n$ | $360°/n$ 回転してから垂直な平面で鏡映する |

分子を変えない操作は必ず数学的な群をなし、そのような群は限られた数しか存在しない。

### このプロジェクトに出てくる点群

| 点群 | 要素 (主なもの) | 例 |
|---|---|---|
| D∞h | 無限回軸、$i$ | [H₂](app:s/2/0/1)、対称な直線の鎖 |
| C∞v | 無限回軸、$i$ なし | 非対称な直線の鎖 |
| D₃h | $C_3$、3 本の $C_2$、$\sigma_h$ | H₃⁺: 正三角形 |
| C₂ᵥ | $C_2$、2 枚の $\sigma_v$ | [H₅⁺](app:s/5/1/1) (MP2): H₃⁺ の 1 つの頂点に、三角形に垂直な H₂ |
| D₂d | $S_4$、$C_2$ 軸、2 枚の $\sigma_d$ | H₅⁺ (DFT): 交差した 2 つの H₂ の間の陽子 |
| T_d | 正四面体 | 球面上の 4 点 |
| C₁ | なし ($E$ のみ) | 対称性がまったくない |

### なぜ重要か

- **縮退したモード。**対称な分子には振動数がちょうど等しい振動がある。H₃⁺ の 2743 cm⁻¹ のモードは 2 回現れる。D₃h では三角形の 2 つのひずみ方が 120° 回転で互いに移り合うので、エネルギーが等しくなければならない。
- **回転エントロピー。** **対称数** $\sigma$ は、分子を自分自身に重ねる回転の数である。H₂ を 180° 回転しても区別できない分子になるので、向きのうち互いに異なるものは半分しかない。$S_\text{rot}$ は $k_B\ln\sigma$ だけ小さくなる ([熱化学](thermochemistry.md))。キャンペーンでの値: H₂ 2、H₃⁺ 6、C₂ᵥ の H₅⁺ 2、D₂d の H₅⁺ 4。
- **最適化は対称性を保つ。**対称な構造の勾配もまた対称なので、最適化プログラムは自分では対称性を破れず、対称な鞍点で止まることがある。ランナーが虚振動モードに沿って構造をずらすのはそのためである ([振動数](frequencies.md#where-this-appears-in-h_clusters))。
- 分光学の**選択則**は各モードの対称性から決まる。

## 許容誤差

実際に計算された構造は決して厳密に対称ではない。最適化は力がゼロではなく*小さく*なったところで止まる。したがって対称性の判定には許容誤差が必要であり、厳しすぎると間違った答えになる。このプロジェクトからの 2 つの例:

- ORCA は、3 本の結合の差が 3·10⁻⁴ Å 未満だった ωB97M-V の H₃⁺ を C₂ᵥ と判定した (フェーズ 1 の知見)。
- ベースラインキャンペーンでは、エネルギーが 10⁻⁶ ハートリーまで、結合長が 10⁻⁴ Å まで等しい RI-MP2 の H₅⁺ の結果 3 つが、C₂ᵥ、C₁、C₁ と判定されている。

## h_clusters での登場箇所

- ORCA の点群と対称数は `result` テーブル (`point_group`、`symmetry_number`) に読み込まれるが、解析には信用しない。
- フェーズ 5 では、許容誤差をもつ判定 (pymatgen の `PointGroupAnalyzer`) を使った独自の `analysis/symmetry.py` と、構造ごとの形の分類 (直線、平面、3 次元) を加える (`doc/Plan.md` §2.2)。
- 重複の判定には対称性をまったく使わない。[距離の指紋](structure-search.md#how-this-project-does-it)が構造を直接比べる。
- ウェブアプリ: [一覧](app:)と各化学種ページに、各構造の点群と形の分類が表示される。
