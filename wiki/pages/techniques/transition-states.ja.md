# 遷移状態と障壁

!!! info "前提"
    [ポテンシャルエネルギー曲面](../foundations/potential-energy-surface.md)、
    [振動数とヘッセ行列](frequencies.md#虚振動数)、
    [解離チャネル](fragmentation.md#生成物か過程か-再配置と障壁)

チャネルの $D_e$ が比べるのはクラスターと生成物だけである。その間の道が生成物より高くまで登るなら、壊れるための本当のコストはその登りの頂上、つまり**障壁**である。それを見つけるには*遷移状態* (TS) を見つける必要がある。遷移状態はポテンシャルエネルギー曲面上の鞍点で、1 つの方向を除くすべての方向で極小、その 1 つの方向に沿っては極大である。

## 考え方

### 手順

1. **端点。** 反応物はクラスターの極小である。生成物には、無限に離れた断片ではなく**生成物錯体**を使う: まだ接している断片 (たとえば [H₅⁺···H](app:s/6/1/2)) を、それ自身の浅い極小まで緩和したものである。経路が各原子をそれ自身に対応させるように、両端の原子の番号はそろえておく。
2. **経路: NEB (nudged elastic band)。** 系のコピーである 8–16 個の*イメージ*の鎖を、端点の間でまとめて緩和する。ばねがイメージを経路に沿って散らばらせ、各イメージは経路に垂直な力だけを受けるので、鎖は**最小エネルギー経路**に落ち着く。*クライミングイメージ*版 (CI-NEB) では、いちばん高いイメージが経路に沿って鞍点まで登る。
3. **TS の精密化。** そのイメージと計算したヘッセ行列から始めて、固有ベクトル追跡法の最適化が 1 つの振動に沿って登り、ほかのすべてに沿って下る。続く振動数計算で鞍点を確認する: **虚振動数がちょうど 1 つ**で、その振動が反応の方向を向いていること。
4. **行き先の確認: 固有反応座標 (IRC)。** TS から両方向に最急降下でたどり、意図した反応物と生成物錯体に着かなければならない。この確認がないと、鞍点が別の反応のものであるかもしれない。
5. **精密なエネルギー。** 経路と TS は勾配が安い計算レベルで求め、極小、TS、生成物のエネルギーをより良い手法で計算し直す。障壁は

$$
E_\text{順} = E_\text{TS} - E_\text{クラスター}, \qquad
E_\text{逆} = E_\text{TS} - E_\text{生成物}
$$

で、電子エネルギーと零点エネルギー込みの両方で求める。TS での ZPE は虚振動数の振動を除く。それは振動ではないからである。

### 鞍点がない場合

多くの解離にはそもそも障壁がない。断片は最後まで引き合い、エネルギーは $D_e$ まで単調に上がる。このとき TS 探索はただ失敗するので、正しい道具は**緩和スキャン**である: 離れていく断片の距離を一連の値に固定し、それ以外を最適化する。単調に上がる曲線は、$D_e$ がしきい値であることを示す。このようなチャネルの速度には、ボトルネックがエネルギーとともに動くので、変分遷移状態理論か位相空間理論が必要である。

### 水素に特有の問題

- **自己相互作用誤差。** DFT は水素移動やプロトン移動の障壁を系統的に過小評価する。C₂ᵥ の [H₅⁺](app:s/5/1/1) の極小を消すのと同じ誤差である ([自己相互作用誤差](../pitfalls/self-interaction-error.md))。構造は MP2、エネルギーは CCSD(T) で求めるのが安全である。
- **スピンが変わる場合。** 最も安い生成物の全スピンがクラスターと違うなら、2 つの状態は別々の曲面の上にある。ボトルネックはどちらかの曲面の鞍点ではなく、2 つの曲面の**最小エネルギー交差点** (MECP) である。
- **共有結合を切る場合。** コア ([H₂⁺](app:s/2/1/2)、[H₃⁺](app:s/3/1/1)) の中の H–H 結合を切ると電子構造が大きく変わり、単一行列式の手法は途中で破綻しうる。結合クラスターの T₁ と D₁ 診断を確かめるか、経路に沿って CASSCF と NEVPT2 を使う。
- **軽い原子核。** 水素は障壁をトンネルし、零点エネルギーも大きい。低い障壁ではそれらが障壁の高さと同じくらい効く。簡単な見積もりは Wigner や Eckart の補正、厳密な方法はインスタントンやリングポリマーの方法である。[H₅⁺](app:s/5/1/1) では、2 つの [H₂](app:s/2/0/1) の端の間を往復するプロトンについて、零点の準位がすでに障壁より上にある ([原子核の量子効果](../pitfalls/quantum-nuclear-effects.md))。

## 例: どのチャネルに何が必要か

| チャネルの種類 | 例 | 再配置 | 道具 |
|---|---|---|---|
| 配位子を失う | [H₇⁺](app:s/7/1/1) → [H₅⁺ + H₂](app:s/7/1/1)、H⁻(H₂)ₖ → H⁻(H₂)ₖ₋₁ + [H₂](app:s/2/0/1) | なし | 緩和スキャン。$D_e$ を確かめるだけと予想される |
| ファンデルワールス分裂 | [(H₂)₄](app:s/8/0/1) → [(H₂)₃ + H₂](app:s/8/0/1) | なし | 緩和スキャン |
| コアの再配置 | [H₆⁺](app:s/6/1/2) → [H₅⁺ + H](app:s/6/1/2) ([H₃⁺](app:s/3/1/1) の三角形ができなければならない) | あり | NEB → TS → IRC |
| スピン変化 | 高スピンのカチオンから低スピンの生成物へ | — | MECP |

[H₆⁺](app:s/6/1/2) → [H₅⁺ + H](app:s/6/1/2) には障壁がないと予想されていた。逆反応が障壁のない [H₂⁺ + H₂](app:s/4/1/2) → [H₃⁺ + H](app:s/4/1/2) に似ているからである ([解離チャネル](fragmentation.md#生成物か過程か-再配置と障壁))。NEB 計算はかわりに小さな障壁を見つける:

- 原子の割り当て方の 2 通りとも、CCSD(T) エネルギーで生成物より 34 meV と 16 meV 高い鞍点 (虚振動数 1 つ、263i と 1023i cm⁻¹) を越える。
- 調和近似の零点エネルギーを入れると、低いほうの鞍点は生成物より 46 meV *低く*なる ($D_0$ = 0.238 eV)。そのためしきい値は $D_0$ のままである。
- 16 meV は、ここで手法が見分けられる大きさより小さい。構造は MP2 のもので、経路に沿って MP2 と CCSD(T) は最大 0.1 eV 違う (端で 0.19 eV と 0.29 eV)。

1 eV 未満のほかのチャネル、[H₅⁺](app:s/5/1/1) → [H₃⁺ + H₂](app:s/5/1/1)、[H₆⁺](app:s/6/1/2) → [H₄⁺ + H₂](app:s/6/1/2) と → [H₃⁺ + H₃](app:s/6/1/2) は、極大なしに生成物まで上がる。確認用の [H₅⁺](app:s/5/1/1) の D₂d の鞍点を通るプロトン移動は 0.0057 eV (0.13 kcal/mol)、虚振動数は 545i cm⁻¹ が 1 つで、零点エネルギー込みでは −0.037 eV である。零点の準位は障壁より上にある。

## [h_clusters](https://github.com/skachano/h_clusters) での登場箇所 { #where-this-appears-in-h_clusters }

- 障壁の研究: `worker/src/hclust/studies/barriers.py`。[H₅⁺](app:s/5/1/1) と [H₆⁺](app:s/6/1/2) (二重項) の 1 eV 未満の各チャネルについて、原子の割り当て方の最も良い 2 通りをたどる。RI-MP2 (レベル L1M、イメージ 10 個) の CI-NEB が、クラスターの極小から 4 Å 引き離した断片まで走る。ORCA は NEB の端点を固定するので、端は生成物錯体に緩和しない。経路に極大があれば数値ヘッセ行列からの `OptTS` が続き、鞍点は虚振動数がちょうど 1 つで、出発したイメージの近くにとどまった (どの距離も 0.25 Å 以上変わらない) 場合だけ数える。エネルギーはすべてのイメージでの CCSD(T) 一点計算から求める。IRC はまだない。`python -m hclust study barriers` で実行し、報告は `data/studies/barriers@baseline.json`。
- 解離の木とユニットは今も生成物のエネルギー ($D_e$) だけを使う: `worker/src/hclust/analysis/units.py`。
- ORCA には手順に必要なものがそろっている: `NEB-TS` (CI-NEB に続けて TS 最適化)、`ZOOM-NEB`、`OptTS`、`IRC`、緩和スキャン (`%geom Scan`)、MECP 用の `SurfCrossOpt`。構造のレベル L1 (ωB97X-D4) と L1M (RI-MP2) には解析的な勾配があり、エネルギーはこのプロジェクトのほかのすべてのエネルギーと同じく CCSD(T) の一点計算で求める。
- 計画: `doc/Plan.md`、フェーズ 8、障壁。
- [ウェブアプリ](app:): [「追加計算」](app:studies)ページの「出ていく道の障壁」。
