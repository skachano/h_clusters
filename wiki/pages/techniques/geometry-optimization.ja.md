# 構造最適化

!!! info "前提知識"
    [ポテンシャルエネルギー曲面](../foundations/potential-energy-surface.md)

構造最適化は分子の形を求める。推測した構造から出発し、原子にはたらく力が消えるまで、ポテンシャルエネルギー曲面を下る方向へ原子を動かす。見つかるのは*最も近い*極小であり、最も低い極小とは限らない。だからすべての形を見つけるには、その上に[構造探索](structure-search.md)が必要になる。

## 考え方

### 勾配をたどる

勾配 $\mathbf{g} = \partial E/\partial\mathbf{R}$ は上り坂の方向を指し、原子にはたらく力は $-\mathbf{g}$ である。現代の手法は勾配を**解析的に**、エネルギー 1〜2 回ぶんほどのコストで計算する。したがって最適化の 1 ステップは、エネルギー 1 回と勾配 1 回のコストである。

単純に $-\mathbf{g}$ に沿って進む (最急降下法) のでもうまくいくが、遅い。細長い谷では底に沿って進まずに、谷を横切ってジグザグに進んでしまう。

### ニュートン–ラフソン法

もっとよい方法は、曲率 (ヘッセ行列 $\mathbf{H}$) も使って現在の点のまわりの曲面を放物線でモデル化し、その放物線の底へ一気に跳ぶことである:

$$
\Delta\mathbf{R} = -\mathbf{H}^{-1}\mathbf{g}
$$

本当の放物線ならこれで 1 ステップで極小に着き、極小の近くでは非常に速く収束する。弱点は極小から遠いところで、そこでは放物線はよいモデルではない。

### 実際の最適化プログラムがすること

- **準ニュートン法**: 厳密なヘッセ行列は高価なので、安価な推測から出発し、これまでに得た勾配を使って改善していく (BFGS 更新)。ORCA の既定である。
- **信頼半径**: ある最大値より遠くへは決して進まず、ステップで上り坂に進んでしまったら半径を縮める。
- **内部座標**: デカルト座標 x、y、z ではなく、結合長や結合角でステップをとる。そのほうが PES が放物線に近い。
- **収束判定**: エネルギー変化、勾配の最大成分と RMS、ステップの最大値と RMS がすべてしきい値を下回ったら止める。`TightOpt` は普通の `Opt` より厳しいしきい値を使う。

## 例: ニュートン–ラフソン法で [H₂](app:s/2/0/1) を最適化する

[`h2_mp2_opt_freq.py`](#the-code) は、伸びた構造 R = 2.0 bohr から出発し、数値微分を使っておもちゃの [H₂](app:s/2/0/1) を最適化する。普通のニュートン法は失敗する:

```text
RHF, plain Newton from R = 2.0 bohr:
  step 1: R = 2.0000 bohr  E = -1.049171  gradient = +1.6e-01  curvature = +0.070
  failed: step 1 jumped to R = -0.26 bohr: not a molecule any more
```

2.0 bohr では RHF 曲線の曲率がほとんどゼロ (+0.07、変曲点の近く) なので、放物線の底ははるか遠くにある。$\Delta R = -0.16/0.07 = -2.3$ bohr となり、もう一方の原子を突き抜けてしまう。0.3 bohr の信頼半径をつけると:

```text
RHF, Newton with a 0.3 bohr trust radius from R = 2.0 bohr:
  step 1: R = 2.0000 bohr  E = -1.049171  gradient = +1.6e-01  curvature = +0.070
  step 2: R = 1.7000 bohr  E = -1.092006  gradient = +1.2e-01  curvature = +0.187
  step 3: R = 1.4000 bohr  E = -1.116714  gradient = +2.8e-02  curvature = +0.482
  step 4: R = 1.3410 bohr  E = -1.117499  gradient = -2.9e-03  curvature = +0.582
  step 5: R = 1.3459 bohr  E = -1.117506  gradient = -2.2e-05  curvature = +0.573
  step 6: R = 1.3459 bohr  E = -1.117506  gradient = -1.4e-09  curvature = +0.573
```

モデルが悪いうちは上限で切られたステップが 2 回あり、そのあとは純粋なニュートンステップになって、誤差は毎回 2 乗になる。勾配は 10⁻³ → 10⁻⁵ → 10⁻⁹ と減る。この最後の速い収束がニュートン法の特徴である。

```python
--8<-- "h2_mp2_opt_freq.py:newton"
```

## 落とし穴

- **局所的であり、大域的ではない。**最適化プログラムは出発した谷の中で止まる。直線状の [H₃⁺](app:s/3/1/1) の鎖は、何かが対称性を破らない限り直線のままである。
- **鞍点で止まる。**出発構造に対称性があると勾配もそれを保ち、最適化が鞍点に収束することがある。それを見分けられるのは[振動数](frequencies.md)だけである。
- **平らな曲面。**弱く束縛されたクラスターには非常にやわらかい方向がある (コアのまわりを滑る [H₂](app:s/2/0/1) ユニットなど)。勾配はどこでも小さく、最適化には多くのステップが必要になる。
- **ばらばらになる。**ランダムな構造から出発すると、断片が離れていって最適化が収束しないことがある。それは失敗ではなく、クラスターについての結果である ([構造探索](structure-search.md#how-this-project-does-it))。

## [h_clusters](https://github.com/skachano/h_clusters) での登場箇所 { #where-this-appears-in-h_clusters }

- タスク `opt` と `optfreq` (`worker/src/hclust/engines/orca.py`) は、レベルの最適化キーワードを加える。L1/L1M には `TightOpt`、選別レベル L0 には `Opt`。
- 最適化サイクルの既定の上限 50 回は、やわらかいクラスターには短すぎた (フェーズ 4: 3 × 50 サイクルのあとも [H₂](app:s/2/0/1) ユニットが滑り続けていた)。そこで L0、L1、L1M は `%geom MaxIter 150` を設定している。
- 最適化がサイクルを使い切ると、ランナーは最後の構造からそれを**再開**する (`worker/src/hclust/runner.py` の `_next_action`、最大 3 回の試行)。これまでのベースラインキャンペーンで、372 回の試行が再開で終わった。フェーズ 3 では、[H₅⁺](app:s/5/1/1) の予備最適化 21 回のうち 16 回が再開を必要とした。
- 最適化された構造はすべて親ジョブとともに保存されるので、初期構造から最終構造までの経路をたどれる (`structure` テーブル)。
