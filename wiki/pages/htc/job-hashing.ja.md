# ジョブのハッシュ化と重複排除

!!! info "前提知識"
    なし。

ハイスループット計算とは、何千もの計算を、クラッシュや修正や新しいステージをはさみながら何日もかけて実行し、また実行し直すことである。それを扱いやすく保つ最も単純な道具は、すべての計算に**内容から導かれたアドレス**、つまり実行したものそのもののハッシュを与えることである。そうすれば同一の計算は自動的に同じアドレスになり、何も 2 度計算されず、どの結果もその正確な入力までたどれる。

## 考え方

### 内容アドレス

SHA-256 のような暗号学的ハッシュ関数は、任意のテキストを固定長の指紋に写す。同じテキストは常に同じハッシュになり、1 文字でも変わればまったく違うハッシュになる。衝突 (同じハッシュをもつ 2 つの異なるテキスト) は事実上起こらない。

計算の結果を決めるものをすべてハッシュすれば、そのハッシュが計算の身元になる:

- 入力ファイル全体 (手法、基底、キーワード、電荷、多重度、座標)、
- プログラムのバージョン。バージョンが違えば結果が違うかもしれないからである。

結果を変えないもの (どのキャンペーンが要求したか、いつ、どのワーカーで) はハッシュに含めない。

### 得られるもの

| 性質 | 方法 |
|---|---|
| **キャッシュ** | 実行前に、このハッシュの完了した結果があるか確かめる。 |
| **重複排除** | 同一の入力をつくる 2 つのステージや初期構造は、1 つの計算を共有する。 |
| **来歴** | 結果のディレクトリ名が、その正確な入力を指している。 |
| **安全な変更** | 設定を変えればハッシュが変わるので、新旧の結果が混ざることはない。 |

これを成り立たせる規則: 入力は**決定的**でなければならない。ランダムな初期構造は明示的なシードで生成し、座標は決まった書式で書くので、同じキャンペーンを 2 回計画するとバイト単位で同一の入力ができる。

## このプロジェクトのやり方

```python
def job_hash(input_text: str, version: str) -> str:
    """Content address of a job: same input + same ORCA version -> same result."""
    return hashlib.sha256(f"orca {version}\n{input_text}".encode()).hexdigest()[:16]
```

先頭 16 文字の 16 進数 (64 ビット) がジョブのディレクトリ `data/jobs/<hash>/` の名前になる。ベースラインキャンペーンの実例、`data/jobs/0022770b3e8c125a/job.inp`:

```text
# hclust H3+ (3) L2 sp
! CCSD(T) aug-cc-pVTZ UHF TightSCF
%maxcore 500
* xyz 1 3
H      0.5434963710    -0.6212694821    -1.0029636119
...
```

`worker/src/hclust/engines/orca.py` の `run_orca()` は、まずそのディレクトリを見る。`job.out` があって `ORCA TERMINATED NORMALLY` を含んでいれば、ORCA を実行せずに保存された出力を読み込む。数えるのは正常終了だけである。クラッシュした実行は中途半端なファイルを残すことがあるからである。

### キャンペーンからの教訓

- **同一のジョブが 2 つ同時に。** m = 1 では、初期構造生成器 `chain` と `random` がどちらも原点にある H 原子 1 個をつくるので、それらのジョブは同じハッシュをもち、したがって同じスクラッチディレクトリを使った。同時に実行すると、一方がもう一方の足元のディレクトリを削除した。現在のスケジューラは、ハッシュがすでに実行中のジョブを待たせる。あとで開始すればキャッシュヒットになる (フェーズ 4 の障害)。
- **キャンペーンの途中で設定を変える。** L0 を `TightOpt` から `MaxIter 150` つきの `Opt` に切り替えたとき、新しいハッシュになったのは新しい L0 ジョブだけだった。完了したジョブは結果を保ち、各ジョブがどの設定を使ったかはハッシュが記録している。
- **再試行は新しいハッシュ。** `SlowConv` をつけた再試行や新しい構造からの再開は入力を変えるので、各試行は固有のハッシュをもち、`attempt` テーブルに保存される。
